# Yash + Shrihan submission

Main project: https://github.com/shrihanchada-rgb/NASA-Space-Apps---YASH-AND-SHRIHAN

Open **Yash-Shrihan-Submission.pptx** for the updated seven-slide presentation. It covers the implemented sensor harmonization, linked area selection, map, archive, downloads, Timestral forecast and evaluation. The reference Califire repository is credited only as the source of the adapted forecast method.

Rebuild with `python -m pip install python-pptx`, then `python submission/build_slides.py` from the repository root. Screenshots come from this project's `docs/demo/`; forecast values come from its `data/processed/regions/US-CA/forecast.json`. The forecast chart is editable in PowerPoint. Source notes are embedded in the slides.

Suggested 3-minute narration: title/problem 25s; data 20s; app 20s; linked-area example 25s; forecast method and chart 35s; validation 25s; impact and links 30s. The current data ends August 31, 2026; September 1–7 forecasts are historical projections. Live forecasting requires newer observations.

Validation: 7 slides; no shapes extend beyond the slide canvas. PowerPoint PDF export could not run in this session, so no PDF is supplied.
